## 🎯 CONSEILS POUR CANVA

### Comment utiliser Canva IA

1. Va sur https://www.canva.com (compte gratuit)
2. Clique "Créer un design" > "Pinterest Épingle" (1000 × 1500 px)
3. Va dans "Éléments" > "Magic Media" (ou "Magic Design")
4. Colle le prompt complet
5. Canva génère plusieurs variantes — choisis la meilleure
6. Ajoute l'image produit dans la zone centrale réservée
7. Télécharge en PNG

### Astuces pro Canva

- **Si Canva ne respecte pas les couleurs exactes** : modifie-les manuellement après génération
- **Si le texte n'est pas exact** : remplace-le manuellement avec la police Space Grotesk (disponible dans Canva)
- **Pour l'image produit** : importe l'image depuis `https://synchro-vie.com/assets/img/produits/[nom]-1.webp` (télécharge d'abord sur ton ordi/phone, puis importe dans Canva)
- **Export final** : PNG pour Pinterest (meilleure qualité que JPG pour le texte)

### Après création des 5 visuels

1. Crée un compte Pinterest Business (https://business.pinterest.com)
2. Crée 5 tableaux (boards) :
   - Biohacking & Longévité
   - Sommeil & Récupération
   - Stress & Cortisol
   - Santé Connectée
   - Récupération Sportive
3. Publie 1 pin par jour à 20h-22h (heure française) — pics de trafic Pinterest
4. Pour chaque pin : titre + description 800 caractères + hashtags (voir PINS_PINTEREST.pdf)
