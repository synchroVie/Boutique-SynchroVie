L'hypertension, le tueur silencieux

On l'appelle le tueur silencieux pour une raison. L'hypertension ne fait pas mal. Pas de symptômes visibles. Mais jour après jour, elle use votre cœur, vos artères, vos reins. Jusqu'à l'accident.

Le B-Pressure Connect vous permet de prendre le contrôle. Mesurez votre tension régulièrement, voyez les tendances, partagez les données avec votre médecin. La prévention commence par la mesure.

  • Validation clinique : Algorithme testé selon les protocoles médicaux. Des résultats comparables aux appareils de cabinet.
  • Détection d'arythmie : Si votre cœur bat de façon irrégulière pendant la mesure, l'appareil vous alerte. Information précieuse pour votre médecin.
  • Synchronisation automatique : Chaque mesure part vers l'application. Graphiques d'évolution, moyennes matin/soir, export PDF.
  • Deux utilisateurs, un appareil : 60 mesures en mémoire pour chacun. Le couple peut se suivre sans mélanger les données.

Caractéristiques

Mesure

  • Plage : 0-299 mmHg
  • Précision : +/- 3 mmHg
  • FC : 40-180 bpm
  • Brassard universel 22-42cm

Fonctions

  • 2 utilisateurs (60 mesures chacun)
  • Détection arythmie
  • Indicateur de mouvement
  • Moyenne 3 mesures
  • Bluetooth 5.0
