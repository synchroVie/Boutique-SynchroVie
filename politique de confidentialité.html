2. Données Collectées et Finalités

2.1 Données de Navigation (Automatiques)

  • Cookies techniques essentiels : panier, préférences langue, session de navigation
  • Logs serveur : adresse IP anonymisée, navigateur, système d'exploitation, pages consultées
  • Finalité : fonctionnement du site, sécurité, statistiques anonymes
  • Base légale : intérêt légitime (art. 6.1.f RGPD)
  • Durée de conservation : 13 mois maximum

2.2 Données de Commande (Vous les fournissez)

  • Identité : nom, prénom, email, téléphone
  • Livraison : adresse postale complète
  • Paiement : données traitées par CinetPay (nous ne conservons JAMAIS vos coordonnées bancaires)
  • Finalité : exécution de votre commande, facturation, service client, garantie légale
  • Base légale : exécution du contrat (art. 6.1.b RGPD)
  • Durée de conservation :
    • Données transactionnelles : 10 ans (obligation fiscale)
    • Données personnelles : supprimées 3 ans après votre dernière commande

2.3 Données Marketing (Avec votre consentement)

  • Newsletter : email, prénom, centres d'intérêt (bio-monitoring, sommeil, etc.)
  • Finalité : envoi de guides santé, protocoles experts, offres personnalisées
  • Base légale : consentement explicite (opt-in)
  • Fréquence : 1 email par semaine maximum, désabonnement en 1 clic
  • Durée de conservation : jusqu'à votre désabonnement + 3 ans

2.4 Avis Clients

  • Données : prénom, initiale du nom, ville, note, commentaire
  • Finalité : affichage public d'avis vérifiés (preuve sociale)
  • Base légale : consentement lors de la soumission
  • Modération : nous vérifions que chaque avis provient d'un achat réel

3. Partage de Vos Données

Nous ne vendons JAMAIS vos données. Vos informations ne sont partagées qu'avec :

Partenaire Données Partagées Finalité
CinetPay (paiement) Email, montant transaction Sécurisation du paiement
Transporteurs (DHL, Colissimo) Nom, adresse, téléphone Livraison de votre commande
Mailchimp/Brevo (emailing) Email, prénom Envoi de la newsletter (si abonné)
Google Analytics (stats) IP anonymisée, comportement Amélioration du site (désactivable)

🌍 Transferts hors UE : Mailchimp (USA) et Google sont certifiés Privacy Shield/clauses contractuelles types. Vos données bénéficient des mêmes protections qu'en Europe.

4. Sécurité de Vos Données

  • 🔒 Chiffrement SSL/TLS 256 bits pour toutes les communications
  • 🛡️ Serveurs sécurisés avec pare-feu, sauvegardes quotidiennes
  • 👤 Accès restreint : seuls les employés autorisés accèdent à vos données
  • 🔐 Mots de passe hashés : même nous ne pouvons pas lire votre mot de passe
  • 🚨 Notification de faille : en cas de violation, vous êtes informé sous 72h

5. Vos Droits (RGPD)

Vous disposez d'un contrôle total sur vos données personnelles :

✅ Droit d'Accès

Obtenez une copie de toutes les données que nous détenons sur vous.

✏️ Droit de Rectification

Corrigez toute information incorrecte ou incomplète.

🗑️ Droit à l'Effacement

Demandez la suppression de vos données (sauf obligations légales).

⏸️ Droit à la Limitation

Suspendez temporairement l'utilisation de vos données.

📤 Droit à la Portabilité

Récupérez vos données dans un format structuré (CSV, JSON).

🚫 Droit d'Opposition

Refusez le traitement marketing ou profilage.

7. Mineurs

Nos produits de santé sont destinés aux adultes. Nous ne collectons jamais sciemment de données d'enfants de moins de 16 ans sans consentement parental. Si vous pensez qu'un mineur a fourni des données, contactez-nous immédiatement.

8. Modifications de Cette Politique

Nous pouvons mettre à jour cette politique pour refléter les évolutions légales ou nos pratiques. Toute modification majeure sera notifiée par email (si abonné) ou via un bandeau sur le site. La version en vigueur est toujours disponible sur cette page avec sa date de mise à jour.
